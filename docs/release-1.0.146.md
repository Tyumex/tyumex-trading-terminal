# Tyumex Terminal Standard 1.0.146

Windows 10 / 11, 64-bit. Standard edition (`next`), without the Author deal-selection module.

Automatic trade screenshots: the terminal captures the whole workspace — every chart — when a position opens, when price comes within a set distance of the Stop Loss or Take Profit, and when the position closes. Shots land in a folder you choose, grouped by instrument and date. Everything is off until you enable it in settings. / Автоматические скриншоты сделок: терминал снимает всё рабочее пространство со всеми графиками в момент открытия позиции, при приближении цены к Stop Loss или Take Profit и при закрытии. Снимки складываются в выбранную папку по инструменту и дате. По умолчанию выключено, включается в настройках.
