# Tyumex Terminal Standard 1.0.145

Windows 10 / 11, 64-bit. Standard edition (`next`), without the Author deal-selection module.

Maintenance build over 1.0.144: the replay simulator starts by bar count or date — whichever is filled — keeps 500 bars of context before the start, and caches loaded history locally, so a repeated start is instant. The engulfment indicator is rebuilt, with its own bull and bear colors and filters. / Техническая сборка поверх 1.0.144: симулятор реплея запускается по числу свечей или по дате, держит 500 свечей контекста до старта и кеширует историю локально, поэтому повторный старт мгновенный. Индикатор «Поглощение» переработан — отдельные цвета и фильтры.
